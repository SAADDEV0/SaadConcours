## Programmation linéaire

- Le produit $P_1$ nécessite 1 heure de travail par jour et le marché ne peut absorber plus de 40 unités de ce produit.
- Le produit $P_2$ nécessite 2 heures de travail par jour.
- Le produit $P_3$ nécessite 3 heures de travail par jour et le marché ne peut absorber plus de 80 unités de ce produit.

| | 1 | 0 | 0 | 0 | 1 | 0 | 40 |
| | 0 | 0 | 1 | 0 | 0 | 1 | 80 |
| $-Z$ | 0 | 0 | 0 | −2 | −1 | −6 | −1120 |
