#### Exercice 1

Pour deux séries statistiques x et y, on dispose des informations statistiques suivantes :

$$\bar{x} = 6{,}388 \; ; \; \bar{y} = 18{,}055 \; ; \; Var(x) = 6{,}793 \; ; \; Var(y) = 13{,}941 \; ; \; n = 18 \; ; \; \sum_{i=1}^{18} x_i y_i = 2198$$

**Q1.** La covariance entre les deux variables est égale à :
a. 6,775 ;
b. 9,150 ;
c. -2,310.

**Q2.** Le coefficient de corrélation linéaire entre les deux variables est égal à :
a. 1,00 ;
b. 0,696 ;
c. 0,390.

**Q3.** La pente de la droite de régression $\hat y = ax + b$ est égale à :
a. -2,505 ;
b. -0,819 ;
c. 0,997.

**Q4.** La constante de la droite de régression $\hat y = ax + b$ est égale à :
a. -30,650 ;
b. 0,410 ;
c. 11,686.

**Q5.** Le pouvoir explicatif du modèle s'élève à :
a. 75% ;
