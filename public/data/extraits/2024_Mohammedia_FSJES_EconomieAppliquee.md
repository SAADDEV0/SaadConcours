### Exercice 1

Soit le modèle keynésien suivant :

Y = C + I + G avec C = 0,8Yd + 10 ; Yd = (Y - T) ; I = 100 ; G = 50 ; T = 50

Y : revenu national ; C : consommation finale des ménages ; I : investissement ; G : dépenses publiques et T : la Taxe.

- Calculer le revenu d'équilibre et déterminer la valeur du multiplicateur.
- Pour atteindre le plein emploi il faut augmenter G de +10. Calculer le revenu de plein emploi.
- Dans le cas où nous voulons varier T au lieu de G, calculer ΔT.
- Comparer entre les deux politiques budgétaire et fiscale ; utilisé le multiplicateur comme indicateur de comparaison.

### Exercice 2

Soit le modèle suivant : Y = 2,5 + 0,35 X1 - 1,12 X2 ; n = 40 ; R² = 0,95 ; D.W = 2,35.

Seuil de risque α = 5%.

1. Tester la signification globale du modèle. (F théorique = 3,23)
2. Calculer R² ajusté et interpréter. Expliquer la différence entre le R² et le R² ajusté.
3. Tester l'absence ou non d'autocorrélation des erreurs.
